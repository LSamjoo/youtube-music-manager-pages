YouTube Music Manager

개인용 Windows 재생목록 관리 프로그램

YouTube Music Manager는 사용자가 선택한 YouTube 공개 재생목록의 곡을 자신의 재생목록에 수동으로 동기화하는 데 사용하는 데스크톱 애플리케이션입니다. Google 계정 접근 권한은 사용자가 승인한 경우에만 사용합니다.

주요 기능

  • 여러 공개 재생목록의 곡 조회 및 수동 병합
  • 영상 ID 기준 중복 곡 검사
  • 새 곡 추가 위치 선택
  • 명확히 삭제된 영상 확인 및 재생목록 정리
  • 변경 전 로컬 백업과 작업 이력 관리

데이터 처리

재생목록 정보는 사용자가 요청한 조회·추가·삭제 작업에만 사용하며, 인증 정보와 백업 파일은 사용자의 PC에 로컬 저장되도록 설계된 애플리케이션입니다. 실제 배포 버전의 처리 동작은 개인정보처리방침을 확인하세요.
